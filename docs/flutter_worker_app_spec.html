User Flow
1
View Queue
Worker sees today's orders sorted by priority (urgent first). Each card shows order ID, item count, suggested box size, estimated weight.
2
Check Alerts
Red alert cards for tamper events, wrong-box assignments, or overdue orders. Tap to view details and resolve.
3
Start Packing
Tap "START PACKING" to begin the verification flow for the next order. Navigates to the product scan screen.
API Endpoints
GET/api/orders?status=PENDING&worker={id}
Fetch assigned pending orders for the current worker, sorted by priority and creation time.
GET/api/alerts?resolved=false&worker={id}
Fetch active alerts (tamper, wrong-box, overdue) for the worker.
